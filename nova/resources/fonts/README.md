# Fonts

Drop the display font here to match the reference image exactly:

- `Orbitron-Bold.woff2` — referenced by `src/renderer/index.css`

Orbitron is licensed under the SIL Open Font License and can be downloaded from
Google Fonts (https://fonts.google.com/specimen/Orbitron). Michroma and
Rajdhani are close alternatives.

If no font file is present the app falls back to the system sans-serif stack so
it still runs — only the exact block-letter look is lost.
